Excluir desportos

Ao filtrar por odds, opções sem preço observado ficam excluídas. Uma odd publicada por uma fonte pode não estar disponível na tua casa.

Atualização ao abrir a página

O GitHub recolhe automaticamente os dados. Para pedir uma nova execução ao fazer refresh, liga o serviço de atualização.

A chave de atualização permanece apenas nesta sessão do navegador. As credenciais GitHub ficam no servidor.

Abrir execuções no GitHub

Confirmar um resultado

Nos desportos sem resultados automáticos, podes confirmar um placar final. O registo fica identificado como confirmação manual.

Futebol e hóquei 1X2: tempo regulamentar. Ténis: sets finais. Basquetebol: resultado final. Só confirmar jogos terminados; sem resultado verificável, mantém pendente.
